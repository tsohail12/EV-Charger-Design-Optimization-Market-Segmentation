# Charger Design Optimization (Market Segmentation)

Project Overview
This project focuses on **optimizing Electric Vehicle (EV) charger designs** by analyzing **market segmentation data**. The goal is to identify how charger types, connector types, and station operators influence **usage patterns and customer demand**, enabling data-driven design and deployment strategies.

Objectives
- Analyze EV charging data to identify key market segments.
- Visualize charger usage trends across operators, types, and connector options.
- Provide insights for **design optimization** and infrastructure planning.

Features
- Sunburst and advanced Plotly visualizations for market segmentation.
- Comparative analysis of charger types and availability.
- Data-driven insights into **charging capacity, usage, and accessibility**.

Tech Stack
- Python
- Pandas / NumPy – Data processing  
- Plotly / Seaborn / Matplotlib – Visualizations  
- Jupyter Notebook – Development & analysis
